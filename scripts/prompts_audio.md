# Prompt tạo âm thanh (ElevenLabs Sound Effects / Stable Audio)

Tải về rồi đặt tên file đúng **mã** (vd `knock_3.mp3`), gửi cho Claude để nạp vào `assets/audio/sfx/`.
Thời gian = giá trị kéo ở thanh **Duration** trên web (không ghi vào prompt). Khoảng lặng ở đầu file được công cụ tự cắt.

| Mã (tên file) | Thời gian | Prompt |
|---|---|---|
| knock_3 | 3s | Three slow, heavy knocks on a wooden bedroom door at night, quiet house, slight echo |
| ghost_stinger | 2s | Sudden horror jump scare hit, loud low boom with a sharp dissonant string screech |
| reverse_swell | 3s | Rising reversed horror swell, tension building whoosh that cuts off abruptly |
| drone_low | 30s | Dark ambient horror drone, low rumbling tone with faint distant whispers, seamless loop |
| heartbeat | 15s | Tense human heartbeat, deep and muffled, steady fast rhythm, seamless loop |
| whisper_eerie | 3s | Creepy female whisper very close to the ear, unintelligible words, breathy |
| door_handle_rattle | 4s | Metal door handle being turned and rattled repeatedly, locked door, indoor |
| door_slam | 1.5s | Wooden bedroom door slammed shut hard, indoor reverb |
| footsteps_slow | 15s | Slow barefoot footsteps on an old creaky wooden floor in a quiet hallway, seamless loop |
| footsteps_run | 3s | Child running fast in sneakers on a wooden floor, panicked |
| floor_creak | 1.5s | Single long creak of an old wooden floorboard |
| flashlight_click | 0.5s | Plastic flashlight switch click, close up |
| flicker_buzz | 2s | Light bulb flickering with electric buzz and crackle |
| breath_close | 5s | Scared child breathing heavily and shakily, very close to the microphone |
| clock_tick | 15s | Quiet wall clock ticking in a silent room at night, seamless loop |
